Workflow

From Idea → Playable

  1. Idea

    Define the core loop and what the player does every few seconds.

  2. Prototype

    Grey-box the mechanic in Unity and test whether it is fun.

  3. Gameplay

    Build the player controller, rules, enemies and win or lose states.

  4. Systems

    Add game state, level progression, UI and save data around the core.

  5. Polish

    Tune feel with animation, audio, feedback and responsive layouts.

  6. Playable build

    Test on target devices, fix what breaks and ship a build.
